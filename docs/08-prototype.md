# Работающий прототип

Прототип находится в папке [`crm-lite`](../crm-lite/). Он связывает воронку, карточку клиента и автоматические задачи с аналитическим обзором.

## Запуск на Windows

```powershell
cd crm-lite
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe seed_demo.py
.\.venv\Scripts\python.exe app.py
```

Откройте <http://127.0.0.1:5050>. Демоданные синтетические. Если нужен пустой старт, пропустите `seed_demo.py`.

## Демо-сценарий за 3 минуты

1. Нажмите **«Добавить клиента»** и сохраните карточку. В разделе **«Задачи»** появится первый контакт со сроком через 15 минут.
2. Нажмите **«Готово»** у задачи. Статус клиента изменится с «Новый» на «В работе».
3. Откройте карточку, выберите статус **«Квалифицирован»**. Появится задача подготовки предложения на 2 дня.
4. Поменяйте этап на **«Предложение»**. Появится задача повторного контакта.
5. Поменяйте статус на **«Выигран»**, этап на **«Успешно»**. Открытые задачи по клиенту отменятся, показатели дашборда пересчитаются.

## API для проверки

| Метод | URL | Назначение |
|---|---|---|
| `GET` | `/api/leads` | Список клиентов |
| `POST` | `/api/leads` | Создать карточку и задачу контакта |
| `PUT` | `/api/leads/{id}` | Обновить карточку и применить правила |
| `GET` | `/api/tasks` | Открытые задачи и признак просрочки |
| `PATCH` | `/api/tasks/{id}` | Завершить задачу (`{"status":"done"}`) |
| `GET` | `/api/overview` | Текущие показатели |
| `GET` | `/api/export.csv` | CSV экспорт |

## Проверка

```powershell
cd crm-lite
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют создание задачи, отсутствие дубля при повторном обновлении, завершение первого контакта и отмену задач при закрытии сделки.

## Технические границы

- Flask + SQLite + HTML/CSS/JavaScript без внешних сервисов.
- Данные находятся в `crm-lite/data/crm.db`; файл исключён из Git.
- Нет регистрации пользователей, внешних уведомлений, фонового планировщика и интеграций.
- Просрочка пересчитывается при открытии списка; это не push-уведомление.
- Демо-импорт создаёт карточки без исторических задач, поскольку время их обработки в исходном наборе неизвестно.
