# Пульс CRM

Готовое упрощённое приложение находится в [crm-lite](crm-lite/README.md).

Приложение работает самостоятельно. Исходные архивы OpenCRM и Salesforce CRM Dashboard послужили ориентиром, но в репозиторий не включаются. Синтетические демонстрационные данные поставляются вместе с приложением.
