# Пульс CRM

Локальная CRM, объединяющая рабочую базу клиентов и сделок из OpenCRM с аналитическим обзором из Salesforce CRM Dashboard.

## Возможности

- Клиенты: добавление, поиск, фильтр, редактирование, удаление и CSV экспорт.
- Сделки: этапы воронки, сумма, вероятность, срок закрытия и ответственный.
- Заметки и даты напоминаний в карточке клиента.
- Автоматические задачи: первый контакт через 15 минут, подготовка КП и повторный контакт через 2 дня; очередь просрочек.
- Дашборд: клиенты по источникам, воронка, выручка по месяцам, прогноз, задачи и открытые обращения.
- Отчёты по сотрудникам и приоритетам.

Данные хранятся в локальном SQLite файле `data/crm.db`. Приложение слушает только `127.0.0.1` и не требует учётных записей внешних сервисов. Денежные значения показаны в USD, как на иллюстрации второго проекта.

## Запуск

```powershell
cd crm-lite
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
python seed_demo.py
python app.py
```

Откройте <http://127.0.0.1:5050>. `seed_demo.py` один раз импортирует 21 синтетическую запись из включённого в проект файла `demo/crm_sample.csv`. Для пустой CRM пропустите эту команду. Порт можно изменить переменной `PORT`, путь к базе — `CRM_DB_PATH`.

## Основы проекта

- OpenCRM: сценарии управления лидами, воронка и заметки.
- Salesforce CRM Dashboard: структура данных и показатели дашборда. Синтетический набор данных в `demo/` повторяет распределения и суммы исходного примера без контактных данных.

Это самостоятельная упрощённая реализация. Она не выполняет рассылки и не подключается к Meta, Outlook, Salesforce или ИИ.

Правила задач и ограничения прототипа подробно описаны в [демо-сценарии](../docs/08-prototype.md), а связь с целевым процессом — в [TO-BE](../docs/03-to-be.md).
